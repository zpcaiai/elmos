# Accessibility evidence

Automated Axe, semantic and keyboard checks run in the five declared Chromium,
Firefox and WebKit desktop/mobile profiles. Manual VoiceOver, NVDA and JAWS
sessions use the signed `device_matrix` external-evidence workflow and must
preserve transcripts, keyboard/focus logs, findings and an independent review.
Automated results cannot substitute for them, so manual assistive-technology
evidence remains `NOT_RUN` until that workflow is really executed.
