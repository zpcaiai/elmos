# Reason Codes

Use stable machine-readable reason codes. Never rely only on free-form prose.

## Ticket / Subject

- `TICKET_MISSING`
- `TICKET_MALFORMED`
- `TICKET_SIGNATURE_INVALID`
- `TICKET_ALGORITHM_INVALID`
- `TICKET_KEY_UNKNOWN`
- `TICKET_ISSUER_INVALID`
- `TICKET_AUDIENCE_INVALID`
- `TICKET_NOT_YET_VALID`
- `TICKET_EXPIRED`
- `TICKET_REPLAYED`
- `SOURCE_DIGEST_MISMATCH`
- `CASE_CATALOG_MISMATCH`
- `HIDDEN_TEST_DIGEST_MISMATCH`
- `RUNNER_PROFILE_MISMATCH`
- `POLICY_DIGEST_MISMATCH`

## Execution

- `PROCESS_NOT_SPAWNED`
- `REQUIRED_STEP_NOT_EXECUTED`
- `PROCESS_EXIT_NONZERO`
- `EXECUTION_TIMEOUT`
- `ZERO_TEST_EXECUTION`
- `TEST_FAILURE`
- `REPORT_MISSING`
- `REPORT_PARSE_FAILED`
- `UNTRUSTED_REPORT`
- `ARTIFACT_MISSING`
- `ARTIFACT_DIGEST_MISMATCH`
- `INFRASTRUCTURE_FAILURE`

## Provenance / Identity

- `UNTRUSTED_RUNNER`
- `EXECUTION_ATTESTATION_MISSING`
- `EXECUTION_ATTESTATION_INVALID`
- `WORKLOAD_IDENTITY_INVALID`
- `SIGNING_PURPOSE_DENIED`

## Mutation / Sabotage

- `MUTATION_SCORE_TOO_LOW`
- `MUTATION_SCOPE_COLLAPSE`
- `SABOTAGE_ESCAPE_DETECTED`

## Semantic Audit

- `SEMANTIC_AUDIT_MISSING`
- `SEMANTIC_AUDIT_INVALID`
- `UNSUPPORTED_SEMANTIC_CLAIM`
- `REQUIRED_CLAIM_UNKNOWN`
- `CONFLICTING_SEMANTIC_EVIDENCE`

## Release

- `POLICY_DENIED`
- `POLICY_UNAVAILABLE`
- `DEPLOYMENT_ARTIFACT_NOT_CERTIFIED`

## Status Mapping

Use `FAILED` when trusted execution establishes that the implementation is wrong. Use `BLOCKED` when infrastructure cannot establish sufficient facts. Both deny certification.
