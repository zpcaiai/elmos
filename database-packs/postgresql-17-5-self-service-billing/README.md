# PostgreSQL 17.5 self-service billing

Experimental exact database pack for Flyway V49 on PostgreSQL 17.5. It covers typed CNY money,
integer Token/Credit quantities, row-locked quota admission, append-only facts, trial lifecycle,
payment reconciliation and tenant RLS.

Local disposable execution is engineering evidence only. Neon execution, production cutover,
rollback rehearsal, independent verification and certification remain `NOT_RUN`.
