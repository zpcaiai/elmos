# 真实部署验收环境需求清单

请提供资源名称、ID、连接或 Secret Reference；不要在对话、Git 或文档中填写密钥、令牌、私钥和数据库密码。
本清单用于准备隔离验收，尚未填入的项目不视为已有环境或已有操作授权。

| 项目 | 提供内容 | 验收用途 |
| --- | --- | --- |
| ELMOS 范围 | tenant、平台 account、workspace、project、environment 引用；操作人与独立审批人 | 身份、资源归属、越权拒绝和审批隔离 |
| 阿里云连接 | 云连接引用、云账号 ID、地域、RAM 角色引用及权限策略 | 短期 STS、权限拒绝、凭证过期/撤销 |
| ECS | 至少 2 台可重启的测试实例 ID、VPC、交换机、安全组、操作系统和架构 | 单机、滚动、故障恢复；Cloud Assistant 可用 |
| 镜像 | ACR 实例/仓库引用，当前与上一稳定版本的不可变镜像摘要、扫描/签名证据引用 | 镜像解析、校验和回滚 |
| 测试应用 | 健康/就绪地址、业务冒烟用例、失败版本；涉及 DB 时提供隔离测试库和恢复点 | 正常部署、失败检测、迁移与回滚 |
| ALB | 实例、HTTPS 监听器、服务器组、后端实例与端口、现有流量权重 | 灰度、蓝绿和流量补偿 |
| DNS/TLS | 测试域名、DNS 记录 ID、旧/新证书引用、允许探测的 IP/端口；适用时的 ICP 证据 | DNS 更新、证书轮换、域名/链/摘要及外部访问验证 |
| ACK/Kubernetes | 集群连接引用、API CA 引用、测试 namespace、允许修改的 Deployment | SSA 冲突、准入、就绪和版本恢复 |
| IaC | 状态后端/工作区引用、工具与 provider 版本/摘要、资源组、允许的资源类型、配额与费用上限 | 保存计划执行、状态冲突、创建/销毁和孤儿清理 |
| GitOps | provider 实例与仓库 ID、测试分支、部署目录、分支保护规则、Argo CD/Flux 应用引用 | 受控提案、合并后的精确版本同步和回滚 |
| 宿主服务 | 控制平面、PostgreSQL、Temporal、CAS、策略/签名、凭证/Secret 服务连接引用 | 真实服务接线、重启恢复、RLS、共享防重放与不可变证据 |
| Runner | 可用的隔离 Runner、Terraform/Helm 固定工具链和镜像、允许的网络策略 | 原生工具执行与超时/进程中断恢复 |
| 可观测性 | OTel/SLS/CloudMonitor 连接引用、测试应用 SLO、指标查询范围 | 部署标记、连续观测、错误预算与回滚 |
| 操作边界 | 允许创建/修改/重启/删除的资源清单；测试时段、费用上限、清理期限和负责人 | 防止误触非测试资源；验收后逐项清理确认 |

建议先提供最小闭环：ELMOS 范围与云连接、2 台 ECS、ACR 两个版本、测试 ALB/域名、宿主服务连接和明确的操作边界。
ACK、IaC、GitOps 可分阶段提供；缺少某项时，该项真实验收明确保留 NOT_RUN。

收到清单后，验收方案应固定：资源快照、每个场景的输入/预期、故障注入范围、回滚点、费用预算、原始证据保存位置、清理与复核步骤。
不得用本地替身测试、源码存在或接口返回成功替代云端运行、真实业务探测和独立验收证据。
