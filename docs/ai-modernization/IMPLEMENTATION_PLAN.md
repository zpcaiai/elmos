# ELMOS AI Modernization Execution Plan

Status values in this plan distinguish repository implementation from external
provider execution. A locally passing contract never changes an external row
from `NOT_RUN`, and no row in this plan constitutes certification.

| Phase | Scope | Repository completion gate | External state |
|---|---|---|---|
| P0.1 | Versioned Hybrid RAG | ACL/tenant negative tests, citation integrity, Recall/NDCG evaluation | embedding provider `NOT_RUN` |
| P0.2 | Semantic Skill routing | exact allowlist, dependency closure, discovery <=16, activation <=8 | model reranker `NOT_RUN` |
| P0.3 | LangGraph repair workflow | real graph execution, attempt budget, independent verifier, checkpoint/resume, idempotency | model/tool providers `NOT_RUN` |
| P1.4 | Elastic projection and OTel | typed mappings/query, bulk idempotency, redacted spans, adapter tests | Elastic/collector `NOT_CONFIGURED` |
| P1.5 | Dify boundary | authenticated API contract, timeout/retry/idempotency, no policy bypass | Dify endpoint `NOT_CONFIGURED` |
| P2.6 | Multimodal and experience memory | modality-preserving anchors, scoped memory lifecycle, rights and promotion gates | OCR/ASR/vision `NOT_RUN` |
| Perf 1-6 | Incremental graph/cache, batching, concurrency, streaming, metrics, benchmarks | deterministic benchmark report with p50/p95, Recall@10, NDCG@10, resume and duplicate-effect metrics | representative production load `NOT_RUN` |
| External gate | exact provider/workload/deployment/verifier inventory, evidence digests, distinct executor/verifier, pinned trust root and detached signature | preflight, report validation, tamper/escape negative tests, exact certificate verification | current run is blocked; production `NOT_CERTIFIED` |

## Dependency order

`typed content + provenance -> hybrid retrieval -> semantic routing -> governed
repair graph -> external projections -> multimodal/memory -> performance gate`.

## Safety and rollback

- Existing deterministic AST/SQL/UIR, authorization, billing, release gates and
  the PostgreSQL execution queue remain authoritative.
- External adapters fail closed when configuration, tenant scope, credentials,
  compatible versions, or receipts are absent.
- Search projections are disposable and rebuildable from immutable versioned
  source records; deleting an index never deletes source assets.
- Agent side effects require an exact allowlisted tool and idempotency key.
- Rollback is removal of the new package modules and optional extras; no schema
  migration or production mutation is performed by local validation.

## Evidence outputs

- focused unit/contract tests under `packages/repository-orchestrator/tests/`
- deterministic benchmark JSON generated by the repository-owned benchmark CLI
- `EXECUTION_REPORT.md` and `evidence-bundle.json` updated after validation
- `EXTERNAL_GATE_RUNBOOK.md`, the external gate plan, and sanitized live observations
