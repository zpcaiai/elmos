# 实时账户用量修改历史

## 2026-07-28

### Added

- 新增 `/api/usage/current` 私有、禁止缓存的实时用量快照接口。
- 新增租户/Actor/短期 Bearer 精确认证和令牌到期校验。
- 新增追加式 JSONL 用量账本读取、事件版本校验、幂等去重、跨租户拒绝和周期聚合。
- 新增 Token 与 Credit 的已用、剩余、整数基点进度及硬停止读模型。
- 新增套餐页连接表单、5 秒近实时刷新、后台暂停、恢复同步和陈旧读数状态。
- 新增进度条可访问性语义及移动端布局。
- 新增当前用量快照和本地用量事件 JSON Schema。
- 新增 Playwright API 身份负向测试和账本增量实时刷新旅程。
- E2E Runner 默认目录改为按测试端口隔离，确保 Web Server、worker 和清理流程读取同一账本。

### Changed

- 套餐页从仅显示静态额度扩展为可连接当前账户的实时消耗面板。

### Preserved

- 人民币套餐目录、Token/Credit 额度和硬停止超额策略保持不变。
- 支付、税务和开票仍为 `NOT_CONFIGURED`。
- 未对账事件不会被计为零或纳入可信已用量。
- 本任务没有修改现有数据库表或执行生产数据库迁移。

### Known limitations

- 当前权威读数适配器仅面向受控本地 Runner 的租户隔离文件账本。
- 生产多用户身份、PostgreSQL/Neon 聚合、纠正事件和提供方 receipt 对账尚未完成。
