# Elmos Framework To Managed Runtime

**Status:** not-certified  
**Owner:** `domain-pack.project-generation`  

## Commercial objective

LangGraph, Spring AI, OpenAI Agents SDK, Google ADK, Microsoft Agent Framework or AI-SIR project is transformed into the declared targets without transferring semantic, execution or completion authority to a provider.

## Mandatory execution

1. select-cloud-target
1. negotiate-capabilities
1. compile-deployment
1. bind-identity-network-telemetry
1. native-deploy-test
1. export-and-rollback-drill
1. seal-evidence

## Native evidence

- capability delta ledger
- native managed deployment
- workload identity and network denial tests
- telemetry and cost reconciliation
- export/exit drill
- rollback and region failover

## Holdout and negative cases

- managed feature unavailable in selected region
- identity misbinding
- service quota exhaustion
- provider-specific artifact export

## Completion boundary

The route may be reported as structurally available after package validation, but only an independent K8 certificate bound to current native evidence may report E5/P05 completion.
