# Elmos Portable Skill Route

**Status:** not-certified  
**Owner:** `domain-pack.project-generation`  

## Commercial objective

Repository knowledge, runbook, existing Skill, prompt package or coding-agent configuration is transformed into the declared targets without transferring semantic, execution or completion authority to a provider.

## Mandatory execution

1. freeze-goal-and-source
1. compile-skill-ir
1. evaluate-trigger
1. emit-host-packages
1. native-host-load
1. cross-host-differential
1. seal-evidence

## Native evidence

- Skill IR round-trip
- per-host native load
- trigger precision and recall
- permission non-expansion
- cross-host normalized trace differential
- signed package and SBOM

## Holdout and negative cases

- unseen repository task
- negative trigger set
- multi-skill collision set
- malicious resource package

## Completion boundary

The route may be reported as structurally available after package validation, but only an independent K8 certificate bound to current native evidence may report E5/P05 completion.
