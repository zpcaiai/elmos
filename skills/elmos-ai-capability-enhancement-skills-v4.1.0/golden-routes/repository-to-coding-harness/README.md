# Golden Route: repository-to-coding-harness

**Current status:** `not-certified`

This directory specifies a repeatable commercial route. It does not claim the route has passed against a customer repository.

## Source

immutable software repository + build/test/runtime evidence

## Targets

pi, deepseek-harness, openharness, codex, claude-code, opencode

## Eligibility

- repository baseline reproducible or explicitly classified
- allowed tool/paths/network declared
- benchmark tasks available

## Required evidence

- package/skill/plugin native load
- sandbox deny tests
- repository task benchmarks
- Git lineage
- independent build/test/review evidence

## Certification rule

Run at least **3 independent repetitions**, including holdout scenarios, failure/recovery, upgrade drift and rollback. Bind every result to exact source and target revisions. E5 requires customer acceptance and deployment evidence; package validation alone cannot satisfy it.
