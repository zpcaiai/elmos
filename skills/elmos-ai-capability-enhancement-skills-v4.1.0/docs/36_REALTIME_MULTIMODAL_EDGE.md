# Realtime, Multimodal and Edge AI

Realtime projects model audio/video transport, turn detection, interruption, barge-in, partial output, consent, safety, latency budgets and degraded networks. Edge projects add model packaging, quantization, device capability, update, offline behavior, telemetry and energy constraints.

Computer-use actions always require scoped authority, bounded plans, confirmation where policy requires, idempotency and side-effect reconciliation.
