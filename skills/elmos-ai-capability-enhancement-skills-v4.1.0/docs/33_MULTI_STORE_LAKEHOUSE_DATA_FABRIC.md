# Multi-store and Lakehouse Data Fabric

DB-SIR expands beyond relational SQL into document/key-value, wide-column, graph, search, vector, event stream and lakehouse table semantics. Migration plans separately model schema, data, CDC, ordering, index lifecycle, ACL, retention, lineage, quality, residency and rollback.

A target is never certified from parser output alone: source and target engines execute the same scenarios, and result/state/transaction/side-effect/plan evidence is compared.
