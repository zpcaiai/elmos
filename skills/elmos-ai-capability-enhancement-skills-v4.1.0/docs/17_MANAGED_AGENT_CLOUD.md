# Managed Agent Cloud Targets

AWS Bedrock AgentCore, Google managed agent platform, Microsoft Foundry Agent Service and Databricks Agents are deployment targets, not semantic or completion authorities.

Each target requires capability negotiation, region and data-residency checks, workload identity, network policy, exact service/SDK pins, telemetry export, full cost ledger, quota/failure scenarios, artifact export, an exit plan and rollback evidence. Provider marketing statements are never native conformance evidence.
