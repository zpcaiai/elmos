# Polyglot Deep Semantics

Implement N compiler-native frontends plus N target backends, not N×N prompt translators. Pair overlays are restricted to irreducible semantic gaps such as memory models, ownership, exceptions, numeric/time/Unicode behavior, ABI/FFI, wire compatibility and framework lifecycle.

Release gates require exact compiler/runtime profiles, native build/start, source maps, deterministic or bounded lowering, differential behavior, performance portability, rollback and current evidence.
