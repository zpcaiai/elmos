# Full-spectrum Automated QA

The QA mesh compiles Proof Obligations into a Validation DAG spanning static, unit, contract, integration, journey, visual, differential, RAG/agent, property, mutation, fuzz, security, performance, soak, chaos, recovery, upgrade and customer holdout testing.

Test selection is risk/impact/freshness aware, but mandatory critical obligations cannot be optimized away. Flaky, UNKNOWN, UNSUPPORTED and WAIVED remain explicit states.
