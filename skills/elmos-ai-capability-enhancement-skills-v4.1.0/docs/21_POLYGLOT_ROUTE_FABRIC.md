# Polyglot Route Fabric

The route fabric implements **frontend → Repository Semantic IR → backend → pair overlay**, not an unmaintainable N×N family of prompt translators. Each exact route envelope binds language, compiler, runtime, framework, build tool, adapter and conformance corpus versions. Semantic gaps become proof obligations and cannot disappear into generated code.

## First commercial routes

1. LangGraph Python → Spring AI Java.
2. OpenAI Agents Python → Microsoft Agent Framework .NET.
3. TypeScript AI UI + LangGraph backend through MCP.

A route certificate is bounded to the exact RevisionSet and is automatically affected by compiler, runtime, adapter, policy or conformance-corpus drift.
