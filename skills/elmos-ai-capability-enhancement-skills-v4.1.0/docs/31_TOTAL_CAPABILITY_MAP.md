# V4 Total Capability Map

The package preserves the 16 canonical v3 routes and adds only non-routable implementation components. The capability fabrics are: AI project generation; portable Skills/plugins; polyglot semantics; relational/NoSQL/search/vector/lakehouse migration; event contracts; model serving and realtime; knowledge and memory; automated QA; formal assurance; zero-trust runtime; platform engineering; product architecture; governance/FinOps; and safe learning.

Every fabric binds Goal, RevisionSet, authority, Proof Obligations, native evidence, side-effect settlement and an independent K8 decision.
