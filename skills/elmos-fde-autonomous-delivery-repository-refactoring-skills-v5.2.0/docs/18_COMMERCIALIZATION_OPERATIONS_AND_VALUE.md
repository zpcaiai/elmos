# 18 — Commercialization, Operations and Value

## Product offers

- Repository Health/X-Ray assessment.
- Legacy modernization pilot.
- Cross-language/framework transformation.
- Database/SQL routine migration.
- AI/Agent production-readiness remediation.
- Continuous architecture/security/quality governance.
- FDE delivery workspace for customer-facing teams.

## Pricing/metering primitives

Engagement fee, assessment scope, repository size/complexity, route, runtime hours, model/compute/storage/network, connector/license costs, retained evidence, private deployment and support tier. Human review remains separately visible.

## Value proof

Track cycle time, engineering effort, defects escaped, build/release time, incident recovery, security exposure, migration throughput, reviewer burden, user adoption and realized business outcome against a pre-agreed baseline. Never guarantee benefit from a model-only estimate.
