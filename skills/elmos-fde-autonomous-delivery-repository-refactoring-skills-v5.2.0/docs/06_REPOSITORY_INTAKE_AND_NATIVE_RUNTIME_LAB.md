# 06 — Repository Intake and Native Runtime Lab

## Intake

Support multi-repo/monorepo, submodules, LFS, generated/vendor/binary artifacts, build files, CI/CD, IaC, schemas/routines, APIs/events, tests, fixtures and documentation. Freeze exact custody and RevisionSet before analysis.

## Runtime reconstruction

Infer OS/architecture, language/compiler/SDK, package manager, lockfiles, system libraries, services, environment variables, network, data and credentials. Classify failures as source, environment, dependency, network, credential, policy or unsupported.

## Lab capabilities

Hermetic sandbox, dependency mirrors, service virtualization, record/replay, database/message containers, fault injection, profiling, traffic sampling, cancellation, checkpoint/resume and artifact hashing. Secret values are brokered directly to tools and never copied into model context.

## Scale

Use incremental inventory, parser caches, content-addressed artifacts, graph partitioning, bounded concurrency and impact invalidation. Benchmark a 500k LOC pilot and a 1M+ LOC route before claiming broad large-repository readiness.
