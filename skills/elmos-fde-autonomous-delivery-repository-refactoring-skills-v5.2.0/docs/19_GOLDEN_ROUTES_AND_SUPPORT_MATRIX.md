# 19 — Golden Routes and Support Matrix

| ID | Route | Scope | Target |
|---|---|---|---|
| gr-fde-discovery-to-pilot | Customer discovery to approved pilot | stakeholders → workflow → baseline → opportunity → SOW → acceptance → access readiness | An approved, bounded, measurable pilot without hidden access or evidence assumptions. |
| gr-repository-xray | Repository intake to trustworthy X-Ray | custody → inventory → build → support profile → runtime evidence → graph | A complete coverage statement with observed, verified-absent, unknown and unsupported areas. |
| gr-full-repository-assessment | Evidence-backed whole-repository assessment | system graph → multi-domain analysis → normalized findings → root-cause portfolio | A deduplicated, evidence-scored issue and unknown register with business impact and root causes. |
| gr-proof-guided-refactor | Plan and execute a behavior-preserving refactor | invariants → alternatives → DAG → atomic ChangeSets → independent verification | Small reversible changes with linked proof obligations and E3 readiness evidence. |
| gr-spring-legacy-modernization | Legacy Java/Spring modernization | characterize → build → decompose → migrate framework → compare → prepare rollout | Spring legacy route including Struts/Servlet migration through canonical Spring Modernization ownership. |
| gr-polyglot-conversion | Repository-level cross-language/framework conversion | source semantics → conversion plan → generated target → native differential verification | Behaviorally constrained conversion without treating transpilation as completion. |
| gr-database-transformation | Schema, routine and data transformation | inventory → semantic mapping → expand/migrate/contract → reconcile → rollback rehearsal | Permission-, routine-, data- and reconciliation-aware database migration evidence. |
| gr-incident-remediation | Incident to verified remediation | triage → containment → evidence → root cause → repair → regression → postmortem | A safe incident response with preserved evidence, verified fix and durable prevention. |
| gr-production-handoff | Readiness to customer handoff | E3 evidence → release rehearsal → training → operations handoff → adoption measurement | A complete handoff packet while reserving production/E4/E5 authority for external execution and certification. |
| gr-portfolio-governance | Multi-repository modernization portfolio | inventory → health/risk/value → route readiness → wave planning → evidence comparison | A capacity-aware, evidence-ranked modernization portfolio rather than an unbounded backlog. |

## Support dimensions

Per route publish exact language, framework, database, build, OS/architecture, deployment, Adapter and version matrix. Each tuple has S0–S5 support depth and E0–E3 evidence. Never infer support from a neighboring version or language family.
