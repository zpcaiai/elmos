# Framework Capability Model

Framework IR capability kinds include:

- endpoint, middleware, filter, interceptor
- dependency, provider, scope, lifecycle
- configuration, feature flag, environment binding
- entity, repository, unit of work, transaction
- queue, event, consumer, producer, schedule, job
- identity, authentication, authorization, session
- serializer, validator, error mapper
- component, widget, view, screen, route, navigation
- state store, cache, query, form, theme, localization
- platform service, permission, notification, storage
- health, metric, trace, log, audit

Each capability references source, configuration, lifecycle, dependencies, contracts, and confidence.
