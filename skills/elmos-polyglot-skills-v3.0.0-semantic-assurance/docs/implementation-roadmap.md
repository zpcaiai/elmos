# Implementation Roadmap

## Phase 0 — Package integration (1–2 weeks)

- install Skills, registries, schemas, policies, and validators
- connect durable run/workflow storage
- define artifact and evidence storage
- establish trusted sandbox contract
- keep all readiness `not-run`

## Phase 1 — Vertical reference route (6–10 weeks)

Recommended: Spring Boot → ASP.NET Core or Spring in-place modernization.

- Java and C# adapters
- snapshot/discovery/contracts/IR
- route planner and DAG
- deterministic rules
- native build/test loop
- API/data differential tests
- evidence and readiness

## Phase 2 — Adjacent high-value routes (8–12 weeks)

- Java ↔ Kotlin
- JavaScript → TypeScript
- Objective-C → Swift
- PHP/Laravel → TypeScript/NestJS
- Python/FastAPI → Go
- C++ → Rust bounded component route

## Phase 3 — UI/mobile and project generation (8–16 weeks)

- React and Flutter Framework IR
- Android/iOS → Flutter
- full-project generator with one approved reference architecture
- visual, accessibility, device, and end-to-end validation

## Phase 4 — Cohort hardening

- route/version/framework compatibility cohorts
- performance and security baselines
- private runners
- canary/dual-run/rollback automation
- route maturity and evidence dashboards

Do not attempt all 182 cross routes at production quality simultaneously. Build shared IR and prove a small number of economically valuable vertical routes.
