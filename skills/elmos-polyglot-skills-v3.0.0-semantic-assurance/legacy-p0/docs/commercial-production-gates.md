# Commercial production gates

E0 Inventory: source/runtime/support surfaces understood.

E1 Build/Parse: source baseline and target clean build.

E2 Semantic: record, decimal, transaction, batch/UI/numerical/ABI obligations pass.

E3 Integration: API/data/security and external integration tests pass.

E4 Shadow: production-like differential/shadow reconciliation within approved thresholds.

E5 Production: rollback tested, cutover approved, observability/SLO/security/supply-chain evidence fresh.

A route cannot skip a mandatory gate because a model reports confidence.
