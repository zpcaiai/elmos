## 通用生产门禁

### 功能

- P0 用户旅程端到端完成；
- 所有操作使用真实实现，不以 mock/TODO 冒充；
- API、事件、Schema 和 UI 状态一致；
- 固定 revision 可复现。

### 可信度

- Confirmed claim 有证据；
- Unknown/Inferred/Recommended 正确标识；
- 随机证据深链有效；
- stale 传播生效；
- 文档、图表、PPT 事实一致。

### 可靠性

- pause/resume/cancel/retry；
- worker kill 恢复；
- 外部副作用幂等；
- 缓存失效正确；
- 备份恢复通过。

### 安全

- 权限矩阵；
- 跨租户；
- Prompt Injection；
- Secret/日志脱敏；
- SVG/DSL/Archive；
- 网络 egress；
- 分享撤销；
- 高危漏洞门禁。

### Artifact

- stable IDs；
- 三方合并；
- 人工锁定；
- 格式可打开；
- 关键内容可编辑；
- claim/evidence map；
- 可离线报告包。

### 性能与成本

- S/M/L 压测；
- p95/p99；
- 大图降级；
- 增量成本；
- ETA P50/P90 校准；
- Token/计算/存储和费率版本化。


### Debug 生产门禁

- adapter capability 与 UI 一致；
- 固定 revision/runtime/image/policy 可复现；
- 生产 attach 默认拒绝；
- Evaluate 默认只读；
- 沙箱逃逸、跨租户、Secret、egress、资源滥用测试通过；
- 权限撤销和 cleanup attestation 达标；
- R0–R3 不混淆；
- Learning Mission 有证据、无答案泄漏并支持 stale 传播。
