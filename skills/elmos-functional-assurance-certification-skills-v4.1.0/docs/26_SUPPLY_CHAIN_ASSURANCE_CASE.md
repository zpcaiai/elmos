# Supply Chain and Structured Assurance Case

Release evidence combines source/build provenance, SBOM/AIBOM, signatures, in-toto attestations, vulnerability applicability/VEX, update trust roots, runtime attestation and transparency checkpoints. A structured assurance case links claims to arguments and immutable evidence, preserving assumptions, limitations, waivers and counterevidence.

Standards and formats are adapters, not completion authorities. Exact production versions and policy profiles must be pinned at release time.
