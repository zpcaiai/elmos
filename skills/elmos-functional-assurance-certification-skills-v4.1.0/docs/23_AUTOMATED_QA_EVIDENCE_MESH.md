# Automated QA and Evidence Mesh

The Proof Obligation Graph compiles into a risk- and impact-selected Validation DAG. Oracle authority order is: compiler/database/protocol runtime; typed contracts; differential behavior; properties/invariants; qualified human labels; calibrated LLM judge. An LLM judge cannot independently certify side effects, data integrity, authorization or E5.

PR, nightly, release and soak matrices use mandatory cells plus covering arrays, historical incidents and affected-module mutation/fuzzing. Flaky is a first-class non-pass status; retries never erase the first failure.
