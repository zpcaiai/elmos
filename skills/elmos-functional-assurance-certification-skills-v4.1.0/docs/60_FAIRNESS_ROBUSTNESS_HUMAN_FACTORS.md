# Fairness, Robustness and Human Factors

## Purpose

Evaluate subgroup and intersectional effects, causal stability, distribution shift, adversarial behavior, calibration, selective prediction, explainability fidelity, automation bias, controllability, fallback and harm/benefit distribution.

## Required implementation pattern

1. Freeze exact Goal, RevisionSet, method, environment, standards/profile versions and authority.
2. Compile claims into Proof Obligations, measurement models, decision rules and competence requirements.
3. Execute native positive, negative, fault, adversarial, repeatability and recovery tests.
4. Quantify uncertainty, limitations, representativeness and external validity.
5. Separate producer, evaluator, reviewer and certification decision identities.
6. Seal evidence in content-addressed/WORM storage and publish machine-verifiable status.
7. Monitor drift, incidents and changes; suspend, scope-reduce, withdraw or recertify as required.

## Non-claim

This document is an implementation and evidence contract. It does not reproduce normative standard text, provide legal advice, establish laboratory competence, confer accreditation or certify any target system.
