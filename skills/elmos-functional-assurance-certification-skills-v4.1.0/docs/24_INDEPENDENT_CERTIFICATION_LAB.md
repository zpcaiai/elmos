# Independent Production Certification Laboratory

Candidate generation and repair submit a frozen RevisionSet to a separate clean-room laboratory. The lab uses separate workload identities, data roles, evidence storage and signing authority. Generator identities cannot write certification decisions, policies or evidence-chain history.

The lab performs reproducible build, native conformance, QA, security, performance/soak, recovery, rollback, customer holdout and side-effect settlement before K8 signs a certificate or returns a typed Blocked Result.
