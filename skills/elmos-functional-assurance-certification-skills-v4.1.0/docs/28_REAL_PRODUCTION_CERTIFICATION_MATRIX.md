# Real Production Certification Matrix

- E0: source, environment and boundary discovery.
- E1: requirements, IR, route and proof obligations.
- E2: exact native import/build/package.
- E3: native start and integrated behavior.
- E4: differential, database, property, security and data assurance.
- E5: performance, resilience, multi-tenancy, supply chain, operations, rollback and customer acceptance.
- P05: exact production deployment evidence.

Mock-only, document-only, file-count, LLM-judge-only and self-certification evidence cannot advance the ladder.
