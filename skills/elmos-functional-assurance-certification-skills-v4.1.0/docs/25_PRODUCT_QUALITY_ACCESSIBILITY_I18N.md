# Product Quality, Accessibility and Internationalization

Commercial productivity certification includes functional suitability, reliability, performance efficiency, security, maintainability, compatibility, interaction quality, flexibility and safety. Generated repositories also undergo representative change and upgrade tasks to prove maintainability rather than merely scoring static metrics.

Accessibility uses automated tests plus qualified manual review; automated scanners alone cannot establish conformance. Internationalization covers Unicode normalization, grapheme boundaries, locale-neutral storage, timezone/DST, calendars, plural rules, number/currency formatting, RTL layout and translation-provider privacy.
