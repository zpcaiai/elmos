# 已知限制与必须诚实披露的边界

## 1. 技能包不是转换器二进制

本包提供可执行工作流、数据契约、规则边界、任务和验证工具，但不会仅靠解压就自动完成任意仓库转换。仍需在 Elmos 代码库中实现 source analyzers、IR、generators、build adapters 和 test harness。

## 2. 平台能力会变化

微信、支付宝、抖音和小红书的 API、组件、工具链、类目、资质、审核和账户权限会变化。任何能力结论都必须绑定：

- platform profile version；
- registry version；
- verified_at；
- developer account/app；
- official reference；
- 实测证据。

## 3. Flutter 不存在普遍的一对一映射

以下常需要 C/D/E：

- 自定义原生插件；
- Platform Channel；
- GPU Shader；
- 复杂 CustomPainter；
- 依赖设备原生能力的插件；
- 高度动态 Widget；
- 游戏或自定义渲染引擎。

局部 Canvas 可作为批准方案，但不能把整页 Canvas 称为等价原生转换。

## 4. 浏览器专属能力

DOM、Portal、Shadow DOM、Service Worker、浏览器扩展 API、复杂 WebRTC、PWA 和某些 CSS 特性可能无等价能力，需要重构或无法实现。

## 5. 第三方组件与许可证

同名替代库不保证行为、许可证、维护、安全或包体积等价。闭源或停更组件可能需要重写。

## 6. 官方工具链自动化

某些平台操作可能要求 GUI、登录态、设备或人工审核。Elmos 可以生成项目、执行离线测试并记录阻断，但不能伪造官方构建、预览、上传或审核成功。

## 7. 真实商业流程

真实支付、退款、资金、内容发布、直播、电商和用户身份涉及账户、资质、地区、隐私与审核。默认只运行 mock/sandbox；生产动作需要授权。

## 8. 视觉等价不是像素完全相同

平台原生控件、字体、系统 UI 和渲染器可能不同。应同时使用结构、关键区域、可用性和业务行为门禁。总体相似度不能掩盖关键控件错误。

## 9. 源应用可能不可运行

依赖停服 API、缺失环境、损坏 lockfile、旧工具链或私有包时，源基线可能无法运行。此时可做静态转换和目标验证，但“与源运行时等价”状态必须是 unknown/blocked。

## 10. 自动修复有边界

自动修复不能替代：

- 业务需求选择；
- 法律/隐私判断；
- 平台资质；
- 真实账户权限；
- 安全审批；
- 发布授权。

默认最多三次；不收敛时应报告，而不是继续消耗成本或降低门禁。

## 11. ETA 与成本

初期缺少同类历史任务时，系统无法可靠预测墙钟 ETA 和成本。必须显示样本不足，并在任务完成后持续校准模型。

## 12. 不支持“静默成功”

任何以下输出都不是成功：

- 空页面；
- 空函数；
- 固定返回 success；
- 未执行的测试写为 passed；
- 编译命令未运行却写构建通过；
- 未取得权限却写能力可用；
- TODO 被计为实现；
- 删除功能后不进入报告。
