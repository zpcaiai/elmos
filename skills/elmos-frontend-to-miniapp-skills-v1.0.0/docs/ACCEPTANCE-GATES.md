# 生产验收门禁

任何任务只有通过全部适用门禁，才能从 `not-ready` 变为 `ready`。门禁不可通过删测试、扩大 mask、降低阈值、关闭扫描或修改报告来“修复”。

## G0 — 请求与源版本

必须满足：

- conversion-request 通过 Schema；
- 源仓库提交、子模块、锁文件与 include/exclude 已固定；
- 目标平台至少一个；
- 降级策略、视觉阈值和最大修复次数明确；
- 真实凭证只以 secret reference 表示；
- 租户、任务和权限上下文有效。

阻断示例：源路径不存在、目标未知、源提交会变化、请求含明文私钥。

## G1 — 项目清单与覆盖率

- 扫描文件覆盖率 100%，排除项有规则和数量；
- 框架候选有证据和置信度；
- 入口、路由、组件、store、资源、依赖和平台 API 均有清单；
- 解析失败文件全部列出；
- 未执行不可信仓库脚本。

## G2 — Source Facts 与 IR

- 所有适用源分析器成功或有结构化错误；
- IR 通过 Draft 2020-12 Schema；
- 节点 ID 稳定、引用闭合、序列化确定；
- source → IR trace 覆盖率 100%；
- 未知语义带置信度和源位置；
- IR 迁移测试通过。

## G3 — 转换计划

- 所有能力、组件、依赖和样式有决策；
- A/B/C/D/E 总数与 finding 明细一致；
- C/D/E 100% 披露；
- 所需权限、后端、资质、审核和测试明确；
- 不存在空实现或无说明删除；
- WebView/Canvas 降级只有在策略与审批允许时出现。

## G4 — 目标代码与官方构建

对每个目标平台：

- 工程结构、页面注册、资源和配置完整；
- 代码格式化、静态分析、类型检查通过；
- 平台 API 经过 adapter；
- 客户端 secret=0；
- 官方 CLI/IDE 构建通过，或平台工具确实无法自动化且有可复核证据；
- 产物、工具版本、退出码和哈希已记录；
- 包体积与平台动态 profile 一致。

## G5 — 功能与行为等价

- 路由和页面完整率 100%；
- 关键业务流程通过率 100%；
- 状态、事件、请求、存储和错误语义无未分类差异；
- 重复提交、弱网、超时、取消和页面销毁后的副作用通过；
- 支付/订单使用 sandbox 或 mock；
- flaky 测试不计为通过。

## G6 — 视觉与交互

- 确定性页面视觉相似度不低于 conversion-request，默认 0.95；
- 关键区域不得仅靠总体平均分掩盖；
- 无文本截断、不可点击控件、严重溢出、安全区遮挡；
- 深色模式、语言、横竖屏和设备矩阵按请求覆盖；
- mask 有理由、范围最小且进入报告；
- 视觉修复后功能门禁仍通过。

## G7 — 性能与稳定性

阈值应在 conversion-request 中按项目定义，至少覆盖：

- 冷启动和首屏；
- 页面切换；
- 长列表；
- 内存增长；
- 网络请求并发和重试；
- 包大小；
- 崩溃和未处理异常。

默认判定原则：关键指标相对源基线或平台预算显著退化时不得通过；没有可比环境时状态为 `unknown`，不能写为 passed。

## G8 — 隐私、安全与供应链

- 高危/严重 secret finding=0；
- 敏感数据流 100% 可追踪；
- 权限按需、最小化并与用途说明一致；
- 第三方 SDK、域名和数据共享已披露；
- 支付回调验签、幂等和重放防护通过；
- 依赖漏洞、许可证与来源检查通过或有批准；
- 日志、截图和报告已脱敏；
- 不可信源代码只在沙箱执行。

## G9 — 证据、审批与发布

- 所有 claim 都有当前 artifact、哈希、工具版本和时间；
- artifact index 无悬空引用；
- 自动修复历史和回滚点完整；
- 任务系统记录输入、输出、节点、系统墙钟运行时和成本；
- 上传、提交审核和发布使用不同审批；
- 平台回执和版本可追踪；
- 未决风险、外部条件和 unknown 状态明确；
- 最终 `ready/not-ready` 与门禁一致。

## 统一判定

```text
ready =
  all(applicable_gates == passed)
  AND unresolved_critical_findings == 0
  AND unresolved_CDE_without_approval == 0
  AND evidence_integrity == true
```

`skipped` 只有在门禁确实不适用且有理由时允许；`unknown`、`blocked`、`failed` 均不能被汇总为 ready。
