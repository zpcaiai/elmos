# ADR-001：采用统一 Semantic IR

- 状态：Accepted
- 日期：2026-08-19

## 背景

源框架和目标平台均超过一个。成对实现转换器会形成输入×输出矩阵，规则重复、测试爆炸且难以追踪。

## 决策

所有 source adapter 先输出框架无关 source facts，再下降到版本化 Semantic IR；所有 target adapter 仅消费 IR 和转换计划。

## 后果

优点：

- 源/目标解耦；
- 规则复用；
- 可增量添加平台；
- 差分和证据可统一；
- 缓存粒度更细。

代价：

- IR 设计与版本迁移需要治理；
- 某些平台特性需 extension 节点；
- 初期闭环比直接模板替换更慢。

## 拒绝方案

- 每个源框架直接生成四个平台；
- 以通用 AST 作为唯一 IR；
- 以某一平台（如微信）作为事实标准再转其他平台。
