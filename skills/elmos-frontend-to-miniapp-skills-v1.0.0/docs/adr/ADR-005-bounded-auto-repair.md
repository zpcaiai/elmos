# ADR-005：自动修复必须有界且上游优先

- 状态：Accepted
- 日期：2026-08-19

## 决策

自动修复默认最多三次。补丁必须来自可重现 finding，优先修改 analyzer、IR、规则、adapter 或模板，并在每次后重跑受影响门禁。

## 停止条件

- 最大次数；
- 重复或等价补丁；
- 需要业务决策；
- 需要扩大权限；
- 需要真实支付/发布；
- 需要降低安全或质量阈值；
- 影响面超过策略；
- 问题不可重现。

## 禁止修复

- 删除测试；
- 放宽断言；
- 扩大视觉 mask；
- 固定返回成功；
- 关闭验签、权限或 secret 扫描；
- 静默删除功能。
