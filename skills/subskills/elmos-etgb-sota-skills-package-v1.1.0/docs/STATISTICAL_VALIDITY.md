# Statistical validity and reproducibility

Probabilistic translation/generation must execute all declared fixed seeds. Report pass distribution, Wilson intervals, worst case, cost and duration variance. Candidate comparisons should predeclare a non-inferiority margin and label underpowered results inconclusive.

A reproducibility bundle includes candidate/plan/corpus/Environment/toolchain/Oracle/normalization digests, commands and seeds. Missing, skipped and unavailable samples stay explicit. Best-of-N reporting is prohibited.

Use `etgb/statistics.py` and `etgb stability`.
