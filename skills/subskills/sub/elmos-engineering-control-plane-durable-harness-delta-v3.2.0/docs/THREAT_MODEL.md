# Threat Model

Protected assets: repository truth, customer code, credentials, policy, execution ownership, evidence, publication rights, deployment targets and certification decisions.

Threats covered:
- prompt-based authority forgery;
- stale permission replay;
- runtime/provider security-semantic drift;
- child-agent privilege inheritance;
- remote worker replay or split-brain owner;
- fake evidence generated by Builder;
- side-effect duplication after crash;
- plugin lifecycle control hidden in observer hooks;
- capability registered but transport dead;
- context provenance loss during compaction/model switch;
- result publication before independent verification;
- exact build artifact differing from published artifact;
- cross-tenant peer/agent routing mistakes;
- workspace file/directory replacement corruption during recovery.

Primary mitigations: host-minted authority, exact-bound approvals, CapabilityLease TTL/fencing, monotonic policy intersection, RuntimeOwner epochs, typed ContextEnvelope, durable timeline/artifacts, ResultFence, Truth Runner, OPA gate, independent Certifier, PublicationBroker and exact artifact verification.
