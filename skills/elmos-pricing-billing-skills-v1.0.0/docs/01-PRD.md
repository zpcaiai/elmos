# Elmos Hybrid Pricing & Billing PRD

## 1. Product objective

为 Elmos 的项目生成、代码转换、仓库分析、自动测试、自动修复和长任务执行建立商业闭环，使客户在执行前知道预算、运行中受到硬保护、执行后能够核对费用，Elmos 能准确核算成本、收入、毛利和供应商费用。

## 2. Target customers

| Segment | Primary need | Default commercial path |
|---|---|---|
| Trial | 体验仓库扫描、估算和少量问答 | 免费额度与严格资源上限 |
| Pro developer | 零散开发、修复、代码分析 | 订阅 + 按量执行额度 |
| Builder | 高频长任务和完整模块 | 订阅 + 较高额度 + 封顶项目 |
| Team | 多成员、共享额度、审批和成本归集 | 席位/平台费 + 共享额度 + 超额 |
| Enterprise | 后付、私有化、SLA、BYOK、合规 | 年度合同 + 承诺用量 + 专项费用 |

## 3. Core customer journeys

### 3.1 Prepaid task

1. 用户连接仓库并描述任务。
2. 系统扫描代码，生成范围、风险、费用区间和机器墙钟 ETA。
3. 用户选择 Economy/Balanced/Best Quality，接受最大预算。
4. 钱包原子预留预算，任务开始。
5. 运行中展示消耗、预计剩余、预算阈值和节点进度。
6. 完成后按实际消耗扣款，释放未使用预算。

### 3.2 Capped project

1. 先执行 discovery。
2. 冻结仓库和需求版本，形成验收测试。
3. 报价为“预计区间 + 最高不超过 cap”。
4. 范围变化自动生成 change order。
5. 里程碑验收后结算，最终不超过 cap。

### 3.3 Fixed-price SKU

只用于标准化任务，例如固定范围架构扫描、标准框架升级、标准文档包或测试补齐包。SKU 必须声明输入上限、输出、验收、排除项和修改轮数。

### 3.4 Enterprise/BYOK

企业合同覆盖公共套餐，支持成本中心、部门预算、审批、PO、信用限额、后付账、承诺用量、私有部署和 SLA credit。BYOK 只排除客户自付模型成本。

## 4. Functional scope

- 价格簿、费率卡、套餐、权益和价格实验
- 预充钱包、付费/赠送额度、冻结、捕获、释放、退款、到期
- 模型/缓存/沙箱/测试/存储/网络/工具计量
- 任务成本和机器 ETA 估算
- 报价、预算授权、阈值提醒、硬暂停、追加预算和低成本重规划
- 项目范围、里程碑、验收、change order、封顶/固定价结算
- 订阅、席位、超额、发票、贷项、续费和 dunning
- 多支付渠道适配、webhook、结算文件和三方对账
- 退款、争议、chargeback、平台责任补偿和人工调整
- 企业合同、承诺用量、BYOK、私有部署和 SLA
- 成本分摊、收入、毛利、报价误差和价格优化
- 客户账单中心、团队预算、运营后台和审计
- 安全、隐私、防欺诈、可观测性、灾备、测试和迁移

## 5. Non-functional requirements

- 财务正确性优先于可用性；不确定时停止写入而非猜测。
- 所有财务命令具备幂等性、租户隔离和审计。
- 关键路径 P95 应由目标仓库 SLO 决定；报价、授权和预算检查不能成为长任务瓶颈。
- 长任务断线后服务端继续执行；重连后返回一致状态。
- 服务端任务中断能够从保存节点恢复，且恢复不产生重复收费。
- 价格、供应商费率、合同和策略版本可历史回放。
- 所有关键表和事件都能通过关联 ID 串起端到端证据。

## 6. Success metrics

- 重复收费率：0
- 未授权硬预算突破：0
- 双分录不平衡交易：0
- 跨租户账单数据泄漏：0
- P90 费用区间覆盖率达到产品批准目标
- 任务报价 MAPE 按任务分层持续下降
- 日终对账差异在 SLA 内清零或进入 suspense 工作队列
- 退款处理时效、项目毛利、缓存节省率、按模型/任务成功成本可观察

## 7. Out of scope for the first release

- 自动给出具体法域税务或会计法律意见
- 在未获批准情况下启用真实生产价格
- 自建通用支付清算网络
- 允许普通用户提取 promotional credits 为现金
- 依赖前端作为唯一预算或权限执行点
