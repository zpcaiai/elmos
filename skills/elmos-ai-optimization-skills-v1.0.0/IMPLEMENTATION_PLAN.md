# 分批实施计划

30项任务、60条宿主验收定义，初始全部not_started/not_run。
默认先B0+B1；B2–B5条件启用；B6针对实际批准scope执行，不强制未启用的可选后端。

| 批次 | 任务 | 交付 |
|---|---|---|
| B0 | T01–T04 | 真实代码盘点、权威映射、基线与评测 |
| B1 | T05–T09 | 精确/关键词证据上下文、安全缓存、真实解释消费者 |
| B2 | T10–T14 | 有条件的后端/增量索引/混合检索/重排 |
| B3 | T15–T19 | 教学/有界修复、动作对账与原生持久恢复 |
| B4 | T20–T23 | 四条业务线的规则、模板与真实差分 |
| B5 | T24–T26 | 可选Dify、DSL与LangChain薄适配 |
| B6 | T27–T30 | 真实E2E、分层性能成本、安全、回滚、独立审批 |

以tasks/tasks.yaml的DAG为准，不机械串行全部批次。条件功能未启用可defer，但已启用则对应资格必需。
所有实现依赖实际host路径/接口；缺源码或运行环境时保持not_run，不编造目录、ETA、测试通过或性能提升。
每批输出输入revision、真实diff、命令/exit/log digest、机器时间和批准等待、结果、回滚与剩余阻塞。
