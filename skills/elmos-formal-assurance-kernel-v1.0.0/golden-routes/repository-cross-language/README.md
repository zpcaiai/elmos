# Repository Cross-language Formal Golden Route

This Golden Route defines the minimum repeatable path for commercial certification of `cross-language`.

## Critical properties

- all source features are classified by semantic profile
- verified rules have proof certificates
- semantic gaps generate discharged obligations or explicit boundaries
- module guarantees satisfy dependent assumptions
- repository entrypoints have composed refinement coverage

## Certification conditions

- Java-to-C# route
- Python-to-Rust route
- concurrency corpus
- reflection/FFI boundary corpus
- E1-E5 complete

A successful package validation is not an E5 certification. E5 requires real repositories/environments, exact toolchain pins, failure injection and signed evidence.
