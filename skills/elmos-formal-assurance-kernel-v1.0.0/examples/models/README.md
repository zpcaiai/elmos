# Formal model examples

These examples are small, reviewable integration fixtures. They are not evidence that the external tools were executed during this artifact build.

Before production use, run each fixture through the exact signed adapter image and capture:

- tool version/digest and command;
- stdout/stderr and exit code;
- parsed status and declared bound;
- proof certificate or counterexample where available;
- wall-clock, CPU and memory;
- TCB and assumption hashes.
