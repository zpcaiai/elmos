# Benchmark corpora

Do not place customer repositories in this package. The production benchmark registry should reference access-controlled corpora by immutable revision and license classification.

Each case records:

- source/target revisions and build manifests;
- feature inventory and semantic profile;
- expected property/result class;
- mutation operators and known seeded faults;
- replay environment;
- privacy/license owner;
- benchmark split to prevent tuning leakage.
