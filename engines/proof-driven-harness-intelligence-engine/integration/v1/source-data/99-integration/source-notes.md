# Source Notes — Oh My Pi concepts intentionally absorbed

This package draws engineering inspiration from the public `can1357/oh-my-pi` repository, including:

- LSP-first code intelligence and broad language-server auto-detection.
- DAP debugger as a first-class agent tool.
- isolated subagents, structured output schemas, model/effort policy, recursion/spawn controls.
- Agent Hub observability and control.
- Advisor/WATCHDOG independent review, severity, dedupe, backlog and quarantine concepts.
- Rulebook/TTSR rule normalization and just-in-time rule injection.
- prewalk/model handoff concepts.
- session fork/resume/fresh/reset distinctions.
- tool-prompt design that teaches WHEN/WHY rather than leaking implementation machinery.
- memory/skill and extensibility concepts.

Elmos-specific upgrades in this package include proof-carrying outputs, semantic authority hierarchy, transactional mutation, workspace ownership/lease/fencing, strict production schemas, semantic/runtime invariants, durable commercial execution, certification integration, and gated skill promotion.
