# K1 — Repository Semantic Intelligence

## Skills

### semantic-lsp-federation
Discover, start, supervise, cache, and query multiple language servers across polyglot repositories.

### compiler-authority-router
Route type/symbol/build questions to compiler or language-native analyzers before lower-authority inference.

### repository-semantic-graph
Build a graph spanning modules, packages, types, symbols, references, calls, inheritance, data access, APIs, transactions, queues, configs, tests, and deployment boundaries.

### semantic-reference-index
Persist definitions, references, implementations, exported symbols, aliases, generated-code links, and unresolved references.

### semantic-call-graph
Create interprocedural call edges with confidence and dynamic-dispatch uncertainty.

### semantic-type-graph
Track inheritance, generics, nullability, variance, type aliases, serialization shapes, schema mappings.

### semantic-dataflow-index
Track key source/sink and transformation paths for request, persistence, message, file, and security-sensitive data.

### framework-semantic-detector
Recognize framework-level semantics beyond language syntax: Spring/Struts/Servlet/.NET/ASP.NET/Django/FastAPI/React/Vue/Flutter and adapters.

### ast-structural-query
Use tree-sitter/ast-grep-style structural patterns when LSP is insufficient.

### repository-prewalk-indexer
Perform cheap, read-only exploration before expensive planning/editing.

### cross-language-semantic-diff
Compare source and target semantic graphs after conversion.

### semantic-uncertainty-map
Represent unresolved dynamic behavior instead of fabricating certainty.

## Required output

`RepositorySemanticGraph` MUST include provenance for each edge and node.

## Acceptance

- exported-symbol reference integrity ≥ 99.99% on certified fixture corpus;
- zero silent unresolved symbols;
- semantic graph refresh is incremental after bounded edits;
- unsupported dynamic edges are marked unknown/approximate;
- source/target semantic diff is consumable by E1/E3 certification.
