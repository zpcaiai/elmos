# Elmos Proof-Driven Harness Intelligence Expansion v1.0.0

This package consolidates the high-value engineering patterns extracted from Oh My Pi and upgrades them for Elmos as a commercial, repository-scale, proof-driven production system.

It is intentionally **not** a 1:1 port of Oh My Pi. The package converts Coding-Agent features into Elmos-grade semantics:

- Tool → Semantic Capability
- Edit → Transaction
- LSP → Semantic Authority
- DAP → Runtime Equivalence Evidence
- Subagent → Isolated Proof Worker
- Rule → Executable Invariant
- Advisor → Independent Assurance Plane
- Memory → Certified Skill Evolution
- Session → Durable Job
- Review → E0–E5 Certification Evidence
- Harness benchmark → Production optimization loop

1. `00-contracts` — canonical schemas and non-negotiable contracts

## Design rule

LLM output is a hypothesis until validated by higher-authority evidence.

Authority order:

Formal proof > compiler > LSP > Semantic IR > AST > runtime evidence > text search > LLM inference.

## Production definition

A capability is not production-ready because it can complete a demo. It is production-ready only when:

- inputs/outputs are typed;
- authority and permissions are explicit;
- mutations are transactional;
- failures are classified;
- rollback is defined;
- evidence is persisted;
- metrics are measurable;
- certification gates can consume the evidence;
- behavior is reproducible on a fixture corpus;
- versioning and deprecation are defined.
