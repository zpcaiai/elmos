# Elmos Proof-Driven Harness Intelligence Engine

This repository-owned Python package implements the typed, fail-closed
foundation for the pinned Proof-Driven Harness Intelligence v1 source
package. The attached ZIP is declarative, untrusted input: none of its
Markdown, Skills, workflows, or examples are imported as execution authority.

The foundation provides canonical serialization, content digests, immutable
contracts, an exact 12-Skill registry, the 260 canonical capability identities
and all 262 source occurrences. The two duplicate source names require an
explicit owner during ordinary resolution. Local code and tests are
self-attested engineering evidence only; external execution and certification
remain `NOT_RUN` and `NOT_CERTIFIED`.
