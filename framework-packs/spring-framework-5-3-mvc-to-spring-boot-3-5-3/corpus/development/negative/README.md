# Negative corpus

All cases are designed but `NOT_RUN`:

- reject Spring Framework versions other than exactly `5.3.39`;
- reject Java versions other than exactly `11` and Maven other than `3.9.11`;
- reject unresolved external servlet-container identity;
- block an existing corporate Maven parent until an approved BOM strategy exists;
- block Spring Security without an exact filter/policy profile;
- block persistence or transactions without exact provider profiles;
- block JSP/view conversion without rendering evidence;
- preserve unresolved XML/property, bean shadowing and handler-order facts as unknown;
- reject transformation output that drops `web.xml` obligations before target replay;
- reject any attempt to claim PASS from static file presence.
